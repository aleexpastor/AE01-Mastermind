# Mastermind Numérico
Juego desarrollado en PHP en el que el jugador debe adivinar
un número secreto de tres cifras distintas.

## Instrucciones del juego
1. Acceder a la aplicación desde el navegador.
2. Introducir un número de tres cifras.
3. Las cifras no pueden repetirse.
4. El juego indica cuántas cifras son exactas y parciales.
5. El jugador dispone de un máximo de 10 intentos.
6. Si acierta las tres cifras, gana la partida.
7. Si agota los intentos, pierde.
8. Al terminar aparece una página con el resultado.
9. Se puede iniciar una nueva partida.
